title: "A decision carries number handles, attachments, and an import source"
---

`numbers` lists each number the statement or reasoning states, with a handle: a record and key, or a runnable command.
`attachments` holds expanded evidence such as logs, kept outside the default read path, for evaluation where applicable.
`imported_from` names the file and heading that a converted record came from.
