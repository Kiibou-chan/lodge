title: "Agents learn the rules from a guide lodge prints"
---

Agents learn the rules from a short guide that lodge prints itself, `lodge guide`, and an agent that only reads gets a shorter one without the writing rules, `lodge guide --read`.
A project's `CLAUDE.md` points at the guide instead of copying it, so the rules live once, versioned with the tool.
