title: "Plans are reviewed, and each task gets a maintainability review"
---

A plan is reviewed before building.
At each task's end a maintainability review looks from two views: practice (duplication, complexity, naming, and documentation against behaviour) and design (boundaries, coupling, and plan rules no test enforces).
Multi-agent builds follow the plan, review, and implement rounds of an existing project.
