title: "The server build follows seven ordered steps"
---

The server build proceeds in this order:
1. TypeScript core, records, check, threads, confirmations, events, API, and command at lodge 0.2 parity with carried tests, importer, and export.
2. Tasks, session reporting, artefacts, hand-over briefs, waiting list, and reporting hooks.
3. Interface: waiting list, task page, artefacts, board, and specification views.
4. Runner, starting local sessions, then cloud sessions.
5. Workflow as data, claimed and checked, usage, and stuck work.
6. Code views and GitHub connector.
7. Sign-in for several people, invitations, roles, and artefact sharing.
Until step 7, one person signs in; passkeys arrive in step 1.
