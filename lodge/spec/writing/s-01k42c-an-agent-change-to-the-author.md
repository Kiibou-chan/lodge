title: "An agent change to the author's text raises a review flag"
---

An agent decision is flagged as awaiting the author when it replaces or narrows an author decision, or changes a specification entry whose last change was an author decision.
A decision the author confirmed counts as an author decision here (LODGE-6), so an agent change to text she approved is flagged too.
