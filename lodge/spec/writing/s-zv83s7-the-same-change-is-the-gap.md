title: "The same change is the gap between the published state and the one about to be published"
---

The same change is the difference between two states of the records: the last published state and the state about to be published.
The published state is the remote tip of the shared branch (in the first user, `lodge`), or the merge base with `main` where a project keeps records on its work branches; in the first user, the gate runs before every push to `lodge`.
