title: "Write feedback advises and does not refuse"
rests_on: [s-edgt71, s-fehz74]

Feedback at write time is advice and never a refusal.
It flags a length over guidance, at each level.
It flags digits in a statement or reasoning that lack a `numbers` handle.
It says so when an agent decision will raise a review flag.
A failing check still refuses the add (s-edgt71).
