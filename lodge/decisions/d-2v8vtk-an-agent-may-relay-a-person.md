An agent may write a person's words into a thread as a message by that person, with where and when; the message is held, and the thread waits for that person as before, until that person, signed in, approves it; a message a person writes signed in under their own name is not held, and one person writing under another's name is refused.

## Reasoning

Asked as STORE-1 (`docs/superpowers/plans/2026-11-02-lodge-server-store/questions.md`), with option C added by the coordinator in the session: a relayed message held for the person's approval, as SRV-2 (d-zzfmj2) holds a decision drafted in a person's name.
The author answered "C".
It replaces the planner's default d-x6vaw8, which refused a relayed message outright.
