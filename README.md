# lodge

A knowledge tool for software development done by agents with a human in the loop.
It makes it easy for agents to handle a project's knowledge in a defined way, and lets the author browse it without a session.
Decisions come first; the tool may grow into wider tooling for larger agent-built projects, coming from the knowledge side.

Context: personal project of Svenja Kernig.
State: design stage. Start at `docs/superpowers/specs/2026-10-29-lodge-design.md`.
